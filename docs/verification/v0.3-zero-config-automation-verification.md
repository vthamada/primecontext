  protection, diagnostics, capabilities, and no silent config overwrite;
- `primecontext prepare <goal>` with optional repeated acceptance, path, and
  term flags and deterministic internal `ContextIntent` generation;
- validation before setup/index writes;
- one best-effort local-index attempt with fallback restricted to an optional
  capability/catalog failure or a known active-writer lock;

  rollback, I/O, configuration, and validation behavior;

  settings excluded before reads;

## Acceptance evidence

1. Repeated setup preserves configuration and unrelated ignore bytes and does
   not duplicate the state-directory entry.
2. A plain goal creates a schema-valid request, envelope, linked receipt, and
   contained plan without a user-authored JSON file.
3. Invalid human input is rejected before config, index, or state creation.
4. Repeated CLI flags are strict and deterministic; unknown, duplicate,
   valueless, empty, and extra arguments fail as one JSON error.
5. An optional index lock is reported as unavailable while live safe sources
   still compile; rollback, I/O, and freshness errors do not become success.
6. A repository-local Markdown note under an Obsidian-compatible vault path is
   selectable, while `.obsidian` settings are excluded before discovery.
7. `doctor` recommends the human `setup`/`prepare` path, and capabilities
   advertise both the human argv and strict agent JSON modes.
8. The disposable demo executes the same public human command twice with
   identical output and removes its synthetic repository.

## Residual boundaries

- PrimeContext still runs from a built source checkout and no package is
  publicly licensed or published.
- The internal TypeScript structural graph is functional but is not the
  external `@colbymchenry/codegraph` product and does not currently traverse
  graph edges for callers, callees, impact, or blast radius.
- Repository-local Markdown compatibility can retain screened source text in
  the ignored SQLite index and selected excerpts in ignored plan state.
- External vault attachment, wikilink/backlink/frontmatter semantics, Obsidian
  Sync, Obsidian URI launch, and note writes remain unimplemented proposals.
- `.primecontext` state is ignored but not encrypted, and secret screening is
  conservative rather than complete DLP.
