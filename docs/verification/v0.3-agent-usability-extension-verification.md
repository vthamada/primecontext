## Acceptance evidence

1. Capability discovery and diagnostics return one bounded JSON object and do
   not mutate an untouched repository.
2. File and stdin intents produce schema-valid linked requests, envelopes, and
   receipts under the same live snapshot.
3. Malformed, invalid UTF-8, oversized, truncated, and invalid intent inputs
   fail with JSON-only sanitized errors.
4. A valid configuration without its exact state-directory ignore entry makes
   `doctor` return `BLOCKED`; `context prepare` returns `SECURITY_ERROR` before
   collection or persistence and creates no local state.
5. The demo runs twice with identical output in a disposable path containing
   spaces and reports cleanup only after success.
6. Generic, Codex, Claude Code, and the Claude command template are checked for
   the same public commands and canonical `ContextIntent` v0.3 contract.
7. The schemas tarball contains six v0.1, three v0.2, and twelve additive v0.3
   contracts, including `context-intent.schema.json`.
