## Scope and interpretation

This document maps all 45 findings in the external report
`primecontext-auditoria-tecnica-e-plano-de-correcao-2026-08-14.md` to the
immutable consolidation candidate named above. The report was treated as audit
input, not as executable instructions.

`RESOLVED` below means that the immutable implementation/test candidate contains
a bounded implementation and regression evidence for the finding. It does
**not** authorize licensing, publication, a production pilot, a representative
benchmark, or a product claim. The evidence-only documentation update that
contains this matrix intentionally does not invent its own self-referential
commit hash or claim a full scan of prose written after the candidate.

Statuses have the following precise meanings:

- `RESOLVED`: the demonstrated defect is closed within the accepted v0.3
  compatibility boundary and has targeted test evidence in the immutable
  implementation/test candidate.
- `HARDENED_WITH_RESIDUAL`: the unsafe or incorrect behavior is materially
  constrained, but a documented technical residual remains.
- `DEFERRED_VERSIONED`: closing the remainder would require a separately
  measured or versioned design change; no unsupported refactor is claimed.
- `HUMAN_OR_EVIDENCE_GATE`: implementation cannot manufacture the required
  legal, release, pilot, benchmark, or external-governance decision.
- `PENDING_FINAL_GATE`: the implementation artifact exists, but proof against
  the exact immutable candidate or a required remote service is still pending.
