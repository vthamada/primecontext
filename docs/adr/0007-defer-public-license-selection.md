# ADR-0007: Defer public-license selection to a human legal/release gate

**Status:** Accepted
**Date:** 2026-08-11

## Context

PrimeContext is being prepared for open-source publication, but the repository does not yet have an approved public license. MIT and Apache-2.0 have been identified as candidates; choosing between them affects patent terms, notices, contribution expectations, package metadata, and downstream use.

License selection is a legal and project-governance decision. It must not be inferred from source visibility, generated by an implementation agent, or treated as a routine documentation default.

## Decision

Defer the public-license choice until an authorized human completes the legal/public-release review.

Until that gate is approved:

- do not add, replace, or imply a `LICENSE` file;
- keep all npm workspaces private and do not publish packages;
- describe PrimeContext as preparing for open-source release, not as presently licensed for public reuse;
- do not accept contribution terms that conflict with the future license decision;
- keep public-release, naming, security-contact, and benchmark-claim decisions independently human-approved.

The release review must document:

1. the authorized decision owner;
2. the selected SPDX license and exact license text;
3. patent, notice, attribution, and third-party dependency considerations;
4. required changes to package metadata, README, contribution policy, and release artifacts;
5. approval to publish the repository and any packages.

The selected license becomes effective only through a deliberate follow-up change that adds the approved text and metadata. That change should update this ADR or add a superseding ADR.

## Consequences

- The v0.1 runtime may be developed and verified locally, but the current checkout is not ready for public redistribution or package publication.
- Absence of a license is an explicit gate, not an accidental omission.
- Automated agents may prepare a comparison or checklist, but cannot make or cross the licensing decision.
- Release documentation must continue to state this limitation until the human-approved license change lands.
